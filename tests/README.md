# Golden Test Suite — investment-radar

اختبارات دائمة (unittest، مدمجة في بايثون، بدون أي مكتبة خارجية) بتقفل السلوك الصحيح للكواشف والمنطق الأساسي، بعد اقتراح تدقيق 24/9/2026.

## التشغيل

```bash
python3 -m unittest discover -s tests -v
```

## الملفات

| الملف | بيغطي |
|---|---|
| `test_smc_detectors.py` | FVG، Liquidity Sweep، Inducement، Order Block، BOS/CHoCH الحقيقي (breakout_check.py) |
| `test_scan_detectors.py` | عتبات القاع المزدوج (v36 regression lock) — لو رجعت تتساهل، الاختبار هيفشل |
| `test_v2_engine.py` | سكور V2، بوابة الدخول، إطار الأهداف (بدون سقف)، فصل WATCH عن الصفقة الفعلية |
| `test_cost_model.py` | نموذج التكلفة — يتأكد إن العائد الصافي دايمًا أقل من الخام، ولا يمكن يتصفّر بالغلط |

## قاعدة مهمة

**أي تعديل مستقبلي في الكواشف دي لازم يشغّل الاختبارات دول الأول.** لو اختبار فشل، يبقى إما (أ) التعديل كسر حاجة كانت شغالة صح، أو (ب) التعديل مقصود والاختبار نفسه محتاج تحديث — قرار واعي، مش صدفة.
